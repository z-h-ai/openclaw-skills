# 龙虾体检报告

## 概述

为 OpenClaw 龙虾（AI员工）生成全面的体检报告，评估其配置健康度和功能完备性。适用于：
- 活动中为参与者生成龙虾体检报告
- 帮助用户了解自己龙虾的配置状况
- 发现配置问题并提供改进建议

## 使用方式

### 快速生成

```bash
# 运行诊断脚本采集信息
bash scripts/diagnose.sh

# 或直接让 AI 读取以下文件并生成报告
# - SOUL.md（人格配置）
# - USER.md（用户信息）
# - MEMORY.md（长期记忆）
# - AGENTS.md（工作规则）
# - HEARTBEAT.md（定期任务）
# - openclaw.json（系统配置）
```

### AI 生成流程

1. 读取龙虾的配置文件（SOUL.md, USER.md, MEMORY.md 等）
2. 检查 channels 配置、cron 任务、skills 数量
3. 评估5个维度的健康度（各20分，满分100分）
4. 生成诊断建议和下一步行动

### **二、健康度评估（5个维度，各20分）**

| 维度 | 检查项 | 评分标准 |
|------|--------|----------|
| **🧠 人格完整度** | SOUL.md 是否有个性？USER.md 是否详细？身份定位是否清晰？ | 0-20 |
| **🔧 功能完备度** | 配置了几个 Channel？有几个 Cron 任务？Skills 数量？ | 0-20 |
| **📝 记忆系统** | MEMORY.md 内容丰富度？日常笔记习惯？是否有长期沉淀？ | 0-20 |
| **⚡ 活跃度** | 最近7天交互频率？Heartbeat 响应？是否有定期任务？ | 0-20 |
| **🛡️ 安全配置** | 权限设置？敏感操作确认？数据保护？ | 0-20 |

**评分等级**：
- **≥80分** → 💪 **健康龙虾**（配置完善，可正常服务）
- **60-79分** → 🔧 **需要调优**（基本可用，有改进空间）
- **<60分** → 🚑 **需要治疗**（配置不足，建议优化）

---

### **三、各维度详细评估**

#### 🧠 人格完整度（20分）

| 检查项 | 分值 | 说明 |
|--------|------|------|
| SOUL.md 存在 | 5 | 基础人格配置 |
| SOUL.md 有个性 | 5 | 不是模板内容，有独特的 tone/vibe |
| USER.md 存在 | 5 | 用户信息配置 |
| USER.md 详细 | 5 | 包含偏好、习惯、工作背景等 |

#### 🔧 功能完备度（20分）

| 检查项 | 分值 | 说明 |
|--------|------|------|
| Channel 配置 | 5 | 至少配置1个沟通渠道 |
| 多 Channel | 5 | 配置2个以上渠道 |
| Cron 任务 | 5 | 有定时任务 |
| Skills 数量 | 5 | ≥5个 skills 得满分 |

#### 📝 记忆系统（20分）

| 检查项 | 分值 | 说明 |
|--------|------|------|
| MEMORY.md 存在 | 5 | 长期记忆文件 |
| MEMORY.md 内容 | 5 | 有实质内容（非空） |
| 日常笔记 | 5 | memory/ 目录有近期文件 |
| 知识沉淀 | 5 | 有方法论、经验总结等 |

#### ⚡ 活跃度（20分）

| 检查项 | 分值 | 说明 |
|--------|------|------|
| Heartbeat 配置 | 5 | 有定期检查机制 |
| 近期交互 | 5 | 7天内有对话记录 |
| 定期任务运行 | 5 | Cron 任务正常执行 |
| 主动行为 | 5 | 有主动推送、提醒等 |

#### 🛡️ 安全配置（20分）

| 检查项 | 分值 | 说明 |
|--------|------|------|
| 敏感操作确认 | 5 | 发送消息前会询问 |
| 权限边界 | 5 | 有明确的 can/can't |
| 数据保护 | 5 | 不泄露敏感信息 |
| 错误处理 | 5 | 有异常处理机制 |
