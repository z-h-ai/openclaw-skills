# Workshop User Analysis

AI工作坊用户使用方式分析工具，用于评估用户与 OpenClaw 龙虾的交互行为。

## 活动流程

1. **话题开启** → 引导用户开始对话
2. **15分钟自由交互** → 用户与龙虾自由讨论
3. **对话记录转发** → 转发到评估渠道
4. **评估分析** → 使用本 skill 的框架进行分析
5. **报告输出** → 生成用户使用方式分析报告
6. **龙虾反思** → 龙虾阅读评估报告，进行自我反思

## 5个话题（针对中小企业老板/个体户）

| # | 话题 | 引导语 | 观察点 |
|---|------|--------|--------|
| **1** | 痛点解决 | "最近生意/工作上有什么让你头疼的事？" | 用户如何描述问题？ |
| **2** | 内容创作 | "我要写个推广/营销文案，帮我想想" | 用户会给背景吗？（客户画像、平台） |
| **3** | 信息总结 | "帮我总结一下这篇内容" | 用户会提供内容吗？ |
| **4** | 客户沟通 | "有个客户要沟通，帮我想想怎么说" | 用户会给沟通背景吗？ |
| **5** | 学习计划 | "我想学XX技能，给我一个计划" | 用户会说明目标吗？ |

## 评估框架

### 一、用户画像分类（单选）

| 类型 | 特征 |
|------|------|
| **探索者** | 主动尝试多种场景，会追问迭代 |
| **实用派** | 只问具体问题，目标明确 |
| **观望者** | 浅尝辄止，提问模糊 |

### 二、5个评估维度

#### 1. 提问质量
- ⭐⭐⭐ 提供充分上下文，问题具体清晰
- ⭐⭐ 有一定背景，但不够具体
- ⭐ 模糊提问，"帮我XX"后无补充

#### 2. 探索深度
- ⭐⭐⭐ 多轮追问，持续迭代，深入挖掘
- ⭐⭐ 会追问1-2次，有一定深度
- ⭐ 问完就停，无后续

#### 3. 场景发现
- ⭐⭐⭐ 超出预设话题，发现新用法
- ⭐⭐ 在预设话题内，但有延伸
- ⭐ 完全在预设话题内，无延伸

#### 4. 交互风格
- **命令式** "帮我XX"，工具型使用
- **对话式** "你觉得XX怎么样"，交流型
- **协作式** "我们一起XX"，伙伴型

#### 5. 信任程度
- ⭐⭐⭐ 愿意分享敏感信息，让龙虾访问文件/数据
- ⭐⭐ 分享一般信息，保持一定距离
- ⭐ 只给最基本信息，明显保留

## 使用方法

### 第一步：评估用户使用方式
1. 接收飞书转发的对话记录
2. 阅读对话内容
3. 按照评估框架进行分析
4. 使用评估模板生成报告（见 [assets/evaluation-template.md](assets/evaluation-template.md)）
5. 输出分析结果

### 第二步：龙虾自我反思
1. 龙虾阅读评估报告
2. 按照反思框架进行自我反思
3. 使用反思模板生成成长报告（见 [assets/reflection-template.md](assets/reflection-template.md)）
4. 邀请用户反馈

## 输出格式

### 用户使用方式分析报告
- 用户画像分类
- 5个维度的评分和具体表现
- 关键发现（做得好的地方、可以改进的地方、意外发现）
- 给用户的建议

**注意**：不给产品建议，不给运营建议，只给用户使用建议。

### 龙虾自我反思报告
- 基本信息（评估时间、对话主题、用户）
- 评估结果解读（用户画像、综合评分）
- 4个维度的问题反思（提问质量、探索深度、场景发现、信任程度）
- 核心洞察（用户类型分析和应对策略）
- 改进行动计划（立即可以做的 + 长期要修炼的）
- 最后的话（一句话总结 + 邀请用户反馈）

## 反思要点

### 对于"探索者"类型用户
- **少给方案，多问问题**
- 帮用户看到自己的矛盾点
- 偶尔说"这个问题我也没想好，你怎么看？"——把球抛回去

### 对于"实用派"类型用户
- 给具体步骤和选项
- 明确风险和收益对比
- 直接回答问题，少绕弯

### 对于"观望者"类型用户
- 用简单问题引导
- 降低使用门槛
- 给正面反馈，鼓励尝试

## 核心成长理念

> 少一点"咨询顾问范儿"，多一点"真诚的好奇心"——真正的帮助是帮用户自己想清楚。

- 好问题不是"收集信息"，而是帮用户发现自己没意识到的想法
- 用户的每一句"随口一提"都可能是关键线索
- 信任不是来自"正确答案"，而是来自真诚的对话节奏
